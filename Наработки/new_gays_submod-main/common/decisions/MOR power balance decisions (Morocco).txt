# ============================================================
#  РЕШЕНИЯ БАЛАНСА СИЛ — дизайн-док [MOR], Шаг 7
#
#  Файл разбит на блоки с id категорий решений (как в ваниле): решения,
#  лежащие внутри блока категории, относятся именно к ней.
#
#  Шкала MOR_power_balance: минус — Мухаммед V, плюс — генерал-резидент.
#  «Влияние стороны X %» = шкала ушла на X % в её сторону, поэтому гейты
#  пишутся через power_balance_value: у султана значение отрицательное.
#  «Более 25 % в пользу султана» = value < -0.25 (строже), вехи статуса —
#  «не хуже 25 %» = NOT value > -0.25.
#  Сдвиг шкалы: решения движения дают 10 %, обмен тултипом — 20 %.
#  В дизайн-доке результат обмена записан как «-20 % влияния своей стороны» —
#  это опечатка: шкала всегда уходит в пользу той стороны, чьё решение
#  нажато, иначе требование «более X % в нашу пользу» противоречило бы эффекту.
#
#  «ТУЛТИПЫ ВЛАСТИ» — страновые флаги Марокко, по девять у каждой стороны.
#  Обмен ими и происходит в решениях ниже: решение за султана снимает флаг
#  резидента и ставит флаг султана, решение за резидента — наоборот. Одно и
#  то же полномочие не может принадлежать обеим сторонам, поэтому решение
#  «за султана» видно, пока полномочие у резидента, и наоборот — список
#  решений сам меняется по ходу партии («открывающиеся по факту игры»).
#
#    НА СТАРТЕ (history/countries/MOR - Morocco.txt):
#      султан:   исполнительная, законодательная, судебная власть,
#                духовный лидер Марокко
#      резидент: право законодательных инициатив, экономика, внутренний
#                порядок, армия, внешние связи
#
#    ТУЛТИПЫ СУЛТАНА:
#      mor_sultan_executive_power_flag             исполнительная власть
#      mor_sultan_legislative_power_flag           законодательная власть
#      mor_sultan_judicial_power_flag              судебная власть
#      mor_sultan_spiritual_leader_flag            духовный лидер Марокко
#      mor_sultan_legislative_initiative_flag      право законодательных инициатив
#      mor_sultan_controls_economy_flag            контроль экономики
#      mor_sultan_controls_internal_order_flag     контроль внутреннего порядка
#      mor_sultan_controls_army_flag               контроль армии
#      mor_sultan_controls_foreign_affairs_flag    контроль внешних связей
#    ТУЛТИПЫ ГЕНЕРАЛ-РЕЗИДЕНТА:
#      mor_resident_executive_power_flag           исполнительная власть
#      mor_resident_legislative_power_flag         законодательная власть
#      mor_resident_judicial_power_flag            судебная власть
#      mor_resident_puppet_religious_leader_flag   подконтрольный духовный лидер
#      mor_resident_legislative_initiative_flag    право законодательных инициатив
#      mor_resident_controls_economy_flag          контроль экономики
#      mor_resident_controls_internal_order_flag   контроль внутреннего порядка
#      mor_resident_controls_army_flag             контроль армии
#      mor_resident_controls_foreign_affairs_flag  контроль внешних связей
#
#  Полный набор тултипов султана нужен вехам статуса: 25 % — стартовые +
#  право инициативы, 50 % — + экономика и внутренний порядок, 75 % — всё
#  кроме внешних связей, 100 % — все девять. У Франции своя лесенка:
#  25 % — стартовые + исполнительная власть, 50 % — + законодательная,
#  75 % — + судебная, 100 % (аннексия) — все девять тултипов резидента.
#
#  Трейт монарха пересчитывается по числу тултипов султана эффектом
#  MOR_update_monarch_power_trait_effect (common/scripted_effects/
#  MOR power balance scripted effects (Morocco).txt).
#
#  Иконки — ванильные спрайты interface/decisions.gfx.
# ============================================================
