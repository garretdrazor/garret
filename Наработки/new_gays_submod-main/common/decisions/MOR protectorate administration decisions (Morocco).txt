#  (common/decisions/categories/MOR protectorate administration categories
#  (Morocco).txt). Решения Франции о смене генерал-резидента Марокко.
#
#  КАК ЭТО РАБОТАЕТ
#  * Генерал-резидент в Марокко — это лидер правящей «авторитарной»
#    (neutrality) силы протектората, поэтому сменяется он наймом другого
#    персонажа: recruit_character = MOR_... (common/characters/
#    MOR characters (Morocco).txt), как и на старте в
#    history/countries/MOR - Morocco.txt.
#  * Узнать, кто сейчас сидит в резидентуре, надёжнее всего по трейту
#    правителя: mor_soft_character — Понсо, mor_resident_satrap — Пейрутон,
#    mor_french_resident_general — Ногес (common/country_leader/
#    MOR traits (Morocco).txt).
#  * Решение лишь открывает событие: одно и то же событие приходит и
#    Франции, и Марокко, а варианты в нём поделены по странам
#    (events/MOR resident-general changes (Morocco).txt).
#  * «-10 % влияния султана» = шкала MOR_power_balance уходит на +0.1
#    в пользу генерал-резидента (минус — Мухаммед V, плюс — резидент).
#  * «-100 очков автономии» = add_autonomy_score = -100 у Марокко.
#
#  ИСТОРИЧЕСКАЯ ОПОРКА
#  22 марта 1936 — Париж снимает мягкосердечного Огюста Анри Понсо и ставит
#  Марселя Пейрутона, «прославившегося» подавлением националистов в Тунисе.
#  16 сентября 1936 — Пейрутона, «резидента-сатрапа», меняют на более
#  гибкого Шарля Ногеса, участника Рифской кампании.
#  Даты в решении не гейтят его: категория открыта с самого старта, игрок
#  сам решает, когда менять резидентов.
#
#  Иконки — ванильные спрайты interface/decisions.gfx.
# ============================================================
