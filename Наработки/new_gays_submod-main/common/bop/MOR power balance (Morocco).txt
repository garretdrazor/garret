#  «Противостояние Мухаммеда V и Французского правления».
#  После установления протектората власть оказалась разделена между султаном
#  и генеральным резидентом: ни один из них не мог действовать без санкции
#  другого. Право вето, формально оставленное султану, и было главным
#  элементом марокканского суверенитета — а французы, перехватив большую
#  часть власти, перешли к прямому администрированию.
#
#  Шкала: левая сторона (отрицательные значения) — Мухаммед V,
#  правая сторона (положительные) — генерал-резидент.
#  Старт: initial_value = 0.5, то есть 50 % в пользу генерал-резидента
#  (выдаётся в history/countries/MOR - Morocco.txt эффектом set_power_balance).
#
#  Категория решений MOR_balance_of_power_category исчезает, когда Марокко
#  становится независимым ИЛИ к власти приходят коммунисты (см. категории
#  решений и common/on_actions/MOR power balance on actions (Morocco).txt).
#
#  ВЕХИ (диапазоны) и их эффекты — по дизайн-доку:
#    100 % султан  +1.00 прироста автономии  -> свобода
#     75 % султан  +0.75                     -> доминион
#     50 % султан  +0.50                     -> колония
#     25 % султан  +0.25                     -> марионетка
#      0-25 %      равновесие, без модификаторов
#     25 % резидент -0.25                    -> Франции доступна колония
#     50 % резидент -0.50                    -> марионетка
#     75 % резидент -0.75                    -> интегрированная марионетка
#    100 % резидент -1.00                    -> поглощение
#  Сами «доступы» — решения common/decisions/MOR power balance decisions
#  (Morocco).txt: они гейтятся значением шкалы и флагами «тултипов власти».
# ============================================================
